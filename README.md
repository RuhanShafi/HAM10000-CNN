<h1 align="center">HAM10000-CNN</h1>
<h3 align="center">By Ruhan Shafi</h3>

Automated classification of pigmented skin lesions on dermatoscopic images from the HAM10000 dataset, comparing a custom Convolutional Neural Network against classical machine learning baselines (SVM, Decision Tree). Built for a Pattern Recognition and Machine Learning (PRML) university project.

## Overview
 
The project classifies dermatoscopic images into 7 diagnostic categories:
 
| Code | Diagnosis |
|---|---|
| `akiec` | Actinic Keratoses / Intraepithelial Carcinoma |
| `bcc` | Basal Cell Carcinoma |
| `bkl` | Benign Keratosis-like Lesions |
| `df` | Dermatofibroma |
| `mel` | Melanoma |
| `nv` | Melanocytic Nevi |
| `vasc` | Vascular Lesions |
